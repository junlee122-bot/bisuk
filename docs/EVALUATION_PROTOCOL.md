# 평가 프로토콜과 데이터 누출 방지

> 요약: 이 저장소의 벤치마크는 **가상(허구) 5건**뿐이라 성능 추정이 아니라 회귀 확인용입니다.
> 실제 판독 성능·오확정률은 연구실이 채택한 판독이 쌓인 뒤 `평가 v2`로 신뢰구간과 함께 봐야 합니다.

## 정답 출처와 격리

- 가상 벤치마크 정답(`benchmarkCases`)은 전용 테이블 `benchmark_cases`에만 있고,
  읽는 경로는 평가 API(`POST /api/evaluation/run`, `POST /api/evaluation/v2`)와 보정 적합뿐입니다.
  후보 생성·교차 매칭·문헌 근거·문맥 모델 코드는 이 테이블을 읽지 않습니다.
- 숨김 셀의 원문(`publishedReading`)·획은 API 응답·변경 이력에서 가려집니다 (통합 테스트로 검증).
- `평가 v2`는 벤치마크에 더해 **연구실이 채택한 판독**(연구원·출판 판독문 출처, 자동 분석 유래 제외)을 정답으로 씁니다.
  대상 셀 자신의 판독은 문맥 모델 학습·자형 표본에서 제외합니다.

## 누출 검사 (Decision Gate `benchmark_leakage`)

규칙은 하드코딩된 `false`가 아니라 실행마다 실제로 검사합니다.

- `benchmarkLeak` 표시 문서는 근거에서 제외하고 `excludedLeakDocumentIds`로 보고합니다.
- 누출 문서에서 **파생된 문서**(derivedFrom 사슬)도 제외합니다 (`excludedDerivedFromLeakDocumentIds`).
- 숨김 벤치마크 셀의 판독이 교차 비교·문맥에 쓰였다면 누출로 판정해 자동 확정을 막습니다.

## 규칙 상태 — PASS / FAIL / NOT_EVALUATED

데이터가 없어 검사하지 못한 규칙은 '통과'로 표시하지 않고 **미평가**로 남깁니다.

| 규칙 | 미평가가 되는 경우 | 자동 확정 차단 여부 |
|---|---|---|
| `strong_chronology_contradiction` | 비석 연대 또는 후보 글자의 최초 확인 연도가 없음 | 미평가면 차단하지 않음(표시만), FAIL이면 차단 |
| `counter_evidence_not_dominant` | (파이프라인에서는 항상 평가) | FAIL이면 차단 |
| `calibration_available` | 데모 셀의 휴리스틱 보정 | 사용자 등록 셀에서 보정 프로파일이 없으면 FAIL → 자동 확정 불가 |

## 신뢰도 보정

- 데모 셀의 '보정 신뢰도'는 **데모 휴리스틱**(가중합)이며 확률이 아닙니다. 화면·Dossier·내보내기에 그렇게 표시됩니다.
- 실제 셀은 PI가 `평가·보정` 화면에서 등위 회귀(isotonic) 또는 Platt 보정 프로파일을 적합·활성화해야 자동 확정이 가능해집니다.
- 적합은 평가 사례 **30건 이상**일 때만 허용합니다. 결과에는 ECE와 신뢰도 구간표가 함께 남습니다.

## 지표 읽는 법

- 자동 확정 중 오답률, 1위 정답률, 자동 확정 비율은 모두 **Wilson 95% 신뢰구간**과 함께 보고합니다.
  예: 현재 가상 벤치마크는 자동 확정 1건·오답 0건이지만, 오답률의 95% 상한은 약 79%입니다 — "오확정 0%"라고 말할 근거가 되지 않습니다.
- 표본이 30건 미만이거나 전부 합성 벤치마크면 평가 결과에 경고가 붙습니다.

## 재현성

- 분석 실행마다 입력을 구성요소(셀 획, 같은/다른 비석 셀, 문헌·주장, 자형표·표본, 이체자, 문맥 코퍼스, 연대 증거, 보정, 엔진 버전)별로
  정규화 JSON sha256 해시로 기록합니다 (`AnalysisRunRecord`).
- `실행 이력·재현` → `지금 데이터로 재실행 비교`는 저장 없이 다시 돌려 입력·결과가 같은지, 바뀌었다면 어떤 구성요소가 바뀌었는지 보여 줍니다.

## 안전 지표 (의미를 좁혀 기술)

| 지표 | 현재 보장하는 것 | 보장하지 않는 것 |
|---|---|---|
| 근거 없는 인용 | 본문에 없는 인용(정규화·이체자 접기 후에도)은 근거로 쓰지 않음 | 인용 문장이 그 셀에 관한 주장인지는 `targetSpecificity`로 표시할 뿐 자동 판정하지 않음 |
| 권리 미확인 자료 재배포 | 공개 내보내기·쇼케이스·파일 API에서 서버가 차단 | 사용자가 내부 내보내기 파일을 직접 유출하는 것 |
| 가짜 측정값 | 단위 미확정 자산은 mm로 표시하지 않음 | 사용자가 잘못 입력한 축척 |
| 오확정률 | 신뢰구간으로 보고 | 소표본에서의 성능 보장 |
