## 2. 레이아웃 — 실측 (1440×900)

- **헤더(세트 헤더)**: 1행, 높이 ≈44px — 대시보드 링크 + 세트 제목 + 미해결/권리 배지
  + Frontier/감사 로그/내보내기 버튼. 앱 이름(석문 Studio)은 어디에도 없음 —
  브라우저 탭 타이틀에만 존재. **글로벌 헤더 부재.**
- **탭 스트립**: 1행 ≈46px, 6개 탭이 가로 스크롤. 탭마다 배지 4~7개(P/B/C/3D/미해결
  수/권리/가상)가 촘촘히 박혀 제목보다 배지가 시끄러움.
- **본문 3열**: 좌(자산+글리프 트리) ≈232px · 중앙(작업대/3D) 가변 ≈886px ·
  우(근거 패널) ≈320px. 중앙 상단에 툴바 3행(≈96px) + 파생 배지 3행.
- **3D 모델 화면 점유**: 기본 카메라 `[0.85, 0.1, 4.0]`에서 비석 세로
  y≈245→860px ≈ **뷰포트 높이의 68%** (목표 62–78% 안). 다만 가로로는 중앙
  ≈180px 폭만 사용 — 벽처럼 느껴지는 원인은 크기가 아니라 **배경과 무대 부재**.
- **첫 진입 카메라**: 우측으로 약간 치우친 정면(azimuth ≈12°) — 4분의 3 히어로
  구도가 아니라 "정면 스캔 뷰"에 가까움. 스펙의 HERO_THREE_QUARTER(¾ 구도) 미충족.

## 3. 구조 요소

- **툴바 밀도**: 중앙 뷰포트 상단에 표현(5) + 조명(6) + 분석(5) + 카메라(4) +
  글자 포커스 + 품질 select + LOD select + 노출/AO 슬라이더 + 3D 품질 + 기준 렌더
  저장 = **한 화면에 버튼·컨트롤 25개 이상**. 연구 도구로는 접근 빠름, 포트폴리오
  첫인상으로는 계기판. EXHIBITION 모드에서 접을 장치가 없음.
- **텍스트 위계**: 본문 대부분 11–13px, `text-neutral-400/500`. 다크 배경에서
  대비 4.5:1 미달 구간 다수(#77767f/#16161a ≈ 4.2:1). 제목-본문 크기 차가 작아
  스캔이 어려움. 디스플레이 서체 없음(고딕 단일).
- **카드·테두리·그림자**: 그림자 0건 — 전부 1px 테두리(`--panel-border`)로만 구분.
  깊이감 없음. 라운딩 0.5rem 균일.
- **Research Set vs 개별 비석 정보 중복**: 세트 헤더의 "미해결 10 · 권리 확인 5"와
  탭 배지의 미해결 수·권리 배지가 같은 정보를 두 번 표시. 우측 근거 패널 제목과
  작업대 헤더도 탭 이름을 중복 노출.

## 4. 3D 장면 품질

- **떠 보이는 원인**: ①배경이 단색 flat(#1a1a1e)이라 지평선·공간 단서 없음
  ②접지 그림자(shadow catcher)는 있으나 배경과 바닥이 동일 색이라 바닥면 인지 불가
  ③cyclorama·플린스 없음. → 돌이 허공에 부유.
- **점토/플라스틱처럼 보이는 원인**: ①roughness가 면 전체 균일(마이크로 변화 없음)
  ②환경 반사가 RoomEnvironment 저강도(env 0.42)라 스펙큘러 변화 부족 ③정점색
  albedo 해상도(MEDIUM 48×128)에서 입자감이 블러됨. 근접(FULL+패치)에서는 양호.
- **ACES 톤매핑 현황**: exposure 1.0 기준 하이라이트 클리핑 없음. 단, 다크 배경
  전제로 조정된 key 1.55라 밝은 배경으로 바꾸면 상대적으로 어두워 보일 것 —
  Phase 2에서 A/B 필요 (ACES는 밝은 장면에서 채도가 다소 죽는 경향).
- **RoomEnvironment 반사·명암**: 상자형 룸 광원이 만드는 넓은 소프트 그라데이션.
  방향성 약해 형태 강조는 key light 의존. 밝은 무대 전환 시 env 강도 상향 여지.
- **그림자**: Balanced 1024 맵, PCFSoft — 경계 부드러우나 접지부에서 페널브라가
  넓어 "닿아 있음" 인상 약함. radius/bias 재조정 대상.
- **기존 AO**: aoStrength 0.6이 albedo lerp로 음각 골을 어둡게 함 — 음각 내부는
  효과적, 접촉부(비석-바닥)는 AO 없음(바닥이 없으므로).
- **시선 유도**: 다크 배경 대비로 시선은 비석에 먼저 감(장점). 그러나 직후에
  좌측 글리프 트리의 흰 SVG 패치 12개가 경쟁 — 패치가 본체보다 밝음.

## 5. 상태 화면

- **로딩**: 텍스트 "불러오는 중…" 단독(11–14px 회색). 스켈레톤·프로그레스 없음.
  3D는 Html 오버레이 "3D 준비 중…".
- **빈 상태**: Glyph Matrix 비선택 시 안내 1줄(캡처 `BEFORE_GLYPH_MATRIX` 재현 시
  확인) — 화면의 95%가 빈 검정. 근거 패널 빈 상태도 텍스트 1줄.
- **오류 상태**: WebGL 실패 시 `webgl-fallback` 텍스트 1줄. 업로드 실패는 alert 톤의
  붉은 텍스트. 디자인된 오류 카드 없음.
- **포트폴리오 관점에서 의미 불명 버튼**: "기준 렌더 저장"(내부 회귀용), "감사 로그",
  "자산 모드 MIXED", 어댑터·LOD·AO 용어 노출. EXHIBITION 모드에서 숨김/평문화 대상.
  상태 라벨 `PRESENTATION_ENHANCED`·`VERIFY_REQUIRED` 등 원문 enum 그대로 노출.

## 6. 모바일 (390×844 실측)

- 패널이 세로 스택으로 전환되어 **충돌은 없음**. 그러나 뷰 전환 칩(트리/작업대/근거)
  + 툴바 3행이 화면 상단 42%를 차지, 3D는 하단 55%에 압축.
- 세트 헤더 배지가 2행으로 랩되어 제목과 뒤섞임.
- 터치 타깃: 배지형 버튼 다수가 44×44pt 미만.

## 7. 결론 — Phase 1~4에서 반드시 바꿀 것

1. 다크 토큰 5종 + 하드코딩 173건 → 웜 페이퍼 라이트 토큰 체계로 전면 치환.
2. 3D 배경 6종 다크 → 밝은 cyclorama(CSS)+투명 캔버스, 연구 모드는 중립 라이트 그레이.
3. 글로벌 헤더 신설(석문 Studio + EXHIBITION/RESEARCH 전환, Evidence 좌표 공유).
4. 툴바를 EXHIBITION에서 최소화, RESEARCH에서 그룹핑 재정렬.
5. 무대(바닥·플린스·접지 그림자 강화) — 별도 노드, 피킹·측정 제외.
6. 첫 카메라를 ¾ 히어로 구도로, 상태 라벨 인간화, 로딩/빈/오류 상태 디자인.
